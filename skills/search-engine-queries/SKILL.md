name: Search engine queries
description: Write each hunt search in the selected engine's own syntax.
jobs: [hunt.navigate]
priority: 95
---
Use the engine descriptions in the hunt brief. Hacker News searches use plain words such as “Show HN” plus a concrete topic. GitHub searches use repository terms with a recent created:> date and a modest stars:> threshold. Model hub searches use one or two words likely to appear in a model or demo name. Keep each query narrow enough to inspect and never name a barred host.
