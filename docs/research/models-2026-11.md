# LLM lineup research: OpenAI, DeepSeek, Meta (as of 2026-11-13)

Scope: current API model IDs, prices, limits, tools, data policy, and independent benchmark evidence for OpenAI, DeepSeek, and Meta. Claude is included only in the benchmark section, as a comparator. No recommendations.

## 3. DeepSeek

### 3.1 Current lineup

- `deepseek-flash`: the documented name is "deepseek-flash". It is served by DeepSeek-V4.1-Flash-1017. The legacy names `deepseek-v4-flash` and `deepseek-v4-flash-vision-exp` are still accepted but the models are retired, and their requests are billed at the Flash price. (`DS-PRICE`, `DS-QS`)
- `deepseek-v4-pro`: model version DeepSeek-V4-Pro-0813. (`DS-PRICE`)
- Both support thinking and non-thinking modes. (`DS-PRICE`)
- Release history: DeepSeek-V4 Preview 2026-04-24; V4-Pro GA 2026-08-13; V4-Flash-Vision-Exp 2026-08-21; V4.1-Flash 2026-09-10; V4.1-Flash-1017 2026-10-17. (`DS-NEWS`)
- Open weights: the 2026-04-24 release states V4-Pro has 1.6T total / 49B active parameters and V4-Flash has 284B total / 13B active. Both open-sourced on Hugging Face. (`DS-NEWS`)

### 3.2 Pricing (first-party, per 1M tokens)

| Model | Input cache hit (off-peak / peak) | Input cache miss (off-peak / peak) | Output (off-peak / peak) |

| deepseek-flash | 0.003 / 0.006 | 0.15 / 0.30 | 0.60 / 1.20 |
| deepseek-v4-pro | 0.022 / 0.044 | 0.66 / 1.32 | 1.98 / 3.96 |

- Peak hours are 01:00-04:00 and 06:00-10:00 UTC, Monday through Friday, excluding Chinese public holidays. Off-peak rates are half of peak. (`DS-PRICE`)
- Concurrency limit: deepseek-flash 2500, deepseek-v4-pro 500. (`DS-PRICE`)
- Search and Fetch APIs are billed per 1,000 successful requests at $0.75 each. (`DS-PRICE`)

### 3.3 Context, output, features

- Context length 1M for both models. Maximum output 384K. (`DS-PRICE`)
- Default output when `max_tokens` is unset: 8K non-thinking, 64K thinking, 128K with reasoning effort max. (`DS-CHAT`)
- JSON output: `response_format` `{"type": "json_object"}` only is documented. The page says the prompt must also instruct JSON. No `json_schema` option appears on the chat completions page. (`DS-CHAT`, `DS-PRICE`)
- Tool calls: supported. The `strict` flag on function definitions is documented as Beta and guarantees schema compliance. (`DS-CHAT`, `DS-PRICE`)
- Responses API and Anthropic API formats: both listed as supported. (`DS-PRICE`, `DS-QS`)
- Vision: supported on deepseek-flash, not on deepseek-v4-pro. (`DS-PRICE`)
- Chat prefix completion and FIM completion: Beta. FIM is non-thinking only. (`DS-PRICE`)
- Hosted web search: no built-in web search tool in the model API. Search and Fetch are separate billed APIs. (`DS-PRICE`)
- Audio input and output: not listed on the pricing page. Unverified.

### 3.4 Deprecations

- `deepseek-chat` and `deepseek-reasoner`: "will be fully retired and inaccessible after Jul 24th, 2026, 15:59 (UTC Time)". They were routing to deepseek-v4-flash non-thinking and thinking. (`DS-NEWS`)
- A third-party page says calls using those names now fail. That was not tested. (cloudzero page surfaced by search, not opened)

- Regulatory or enterprise restrictions on DeepSeek's first-party API: not searched. Unverified.
